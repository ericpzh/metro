# Repository rules

Use `.agents/skills/metro-repo/SKILL.md` to route work to the owning game, test,
web or model skill. Its
[performance reference](.agents/skills/metro-repo/references/performance.md) is
the measured-state record: measure the reported interaction, record results
there, keep a deterministic regression, resolve one scene pick per event, and
keep preview work separate from document commits.
