# Station Designer Unity port (`unity/`)

The Unity port ships the station-building sandbox as a Unity 6 URP runtime behind the shared React 19 UI shell — as a packed WebGL player, a live in-Editor Play Mode session, and a `StandaloneWindows64` `.exe` build — while keeping `GAME-SPEC.md` and the TypeScript game (`game/src/`) as the behavioral oracle and asset generator.

- For Three.js / source GLB conversion, CLI recipes, `prove-model.ps1`, `prove-bench.ps1`, `glTFast` basis/material rules, station finishes and catalogue generation, read [the Unity asset conversion sub-guide](references/assets.md).
- For game rules, module specifications and passenger rigs, consult `metro-game`, `metro-game-test` and `metro-model`.
- For reproducible performance investigations, use [the shared performance reference](../metro-repo/references/performance.md) — never create a parallel Unity performance document; functional/smoke durations belong in test and run reports.
- Local working plans and RCA notes under `unity/plan/` are gitignored (untracked in Git, kept locally when present); treat C#/TS source and `unity/tests/` as the committed source of truth and never link to `unity/plan/` from tracked docs.

## Load-bearing contracts

### 1. Coordinates, handedness & flat-box winding (`StationCoordinates.cs`, `GeometryKit.cs`)

- Saved documents, `Metro.Sim` and `Metro.Build` stay in source axes: plan `(x, y)` in metres, elevation `z` in metres (`STOREY_HEIGHT = 5`, station `levelBase`; integer `Facts.Z` drives storey indexing while `Facts.ExactZ` preserves fractional height for wall-mounted plaques/displays).
- `Metro.View.StationCoordinates` is the **sole** conversion point (`ModulePlacement` delegates to it): document `(x, y, z)` maps to Unity world `(x, z, y)`. Do not add implicit `+0.5` or `+1` in raw `Point` conversions; use `CellCenter` and `FloorTop` explicitly.
- Saved quarter-turns map to **`-90° * rot` Unity yaw** (`ModuleRotation(rot)`).
- Family builders receive a parent `Transform` already placed in world space and build in local space — never swap axes a second time. Note that opening GLBs wrap Z-up content in a `-90°`-about-X node, so swing door hinges rotate around `OpeningAxis.Z` (`SwingUp`) rather than local Y, cabinet measurements on `glTFast`-mirrored prefabs must transform bounds into holder space (`TryMeasureGateJambInHolder`), corner-pivoted prefabs whose bay offset is already baked relative to cell `(0, 0)` (`court-{pickleball,badminton,divider}`) skip `ModulePlacement.RunCentre` and register measured `TryDocumentBounds`, and `MeshTopology.Lines` submeshes (`court-net-mesh`) must be guarded before calling `GetTriangles(...)` in `StationExplodedTrayBuilder` and `StationPlacementPreview`.
- Procedural box parts (`BoothModuleViews`, `VerticalModuleViews`, `PsdReturnTrim`, etc.) must emit 24-vertex outward-wound quads with per-face flat normals via `GeometryKit.BoxFaces` — never 8-vertex shared-corner perimeter tables, which produce inverted bowtie triangles and smoothed sheet-metal normals (`MeshWindingTests`). Procedural ramp/stair parts in `VerticalModuleViews.PartMesh` likewise extrude closed stadium/parallelogram outlines (`ExtrudePolygonDoc`) and smooth torus/hemisphere shells (`TorusArcDoc`, `HemisphereDoc`) in document axes before converting once via `Doc(...)`, and `StationCellMesher.MeshSession.FaceRecord` keys faces by a lossless 128-bit `FaceRecordKey` so two's-complement odd `±y, ±z` cells never collide.
- Camera snapshots convert Unity's rendered `right`, `up` and `back = -forward` back into document axes so React's `ViewCube` dots its six face normals directly without quaternion handedness ambiguity.

### 2. Self-registration, per-world lifecycle, artwork recapture & dual-transport publishing

- Features self-register via `[RuntimeInitializeOnLoadMethod(BeforeSceneLoad)]` (or `AfterSceneLoad` / `StationGameHost.Awake` bootstrap for `StationViewFeature`, `StationStatisticsFeature`, `PassengerServiceFeature`, `StationRenderRig`, `StationPointerRouter` and `StationDesktopUiPresenter`) into `StationRenderers` (15 renderers), `StationCommandHandlers` (11 handlers), `StationFrameSinks` (8 sinks ticked every frame with `StationFrameClock`: `Tick`, discontinuity `Epoch`, `SimTime`, `PresentationSeconds`, sub-tick `Fraction`, `Playing`), and `host.RegisterStateContributor(...)` (13 contributors). `StationGameHost` contains no per-family branches.
- **Staging & visibility recapture rules:** `StationLoadCoordinator` builds the incoming `StationWorldView` *before* disposing the outgoing world (`Coordinator.BeforePreviousDispose` fires right before old-world teardown so `StationExplodedView` closes cleanly on station switches without closing on rejected opens). Every `IStationViewRenderer` singleton **must** key its state per `StationWorldView` and prune only `IsDisposed` worlds in `Release()`. Whenever a view binds runtime materials/textures after registration (`billboard`, `tv`, `linemap`, `calligraphy`, `clock`, `exit`, `psd`), it **must** call `world.RecaptureArtwork(renderer)` (`StationVisibilityTarget.Recapture` → `StationVisibilityPalette.SyncDerived` updating cached `Ghost`, `Clear`, and section-shader clones **in place** without destroying shared clones worn by sibling renderers, and immediately reapplying the active mode) and set glTFast ShaderGraph `baseColorTexture` / `baseColorFactor` alongside URP `_BaseMap` (`StationSignMaterials.ApplyTexture`) so both `Base` and ghosted storeys display the live artwork.
- **Outbound host publishing vs pure-C# runtime artwork:** Host-initiated browser requests (`StationSignSignage`, `PsdHeaderArtwork`, `StationExitArtwork`) must publish via `StationGameHost.PublishOutbound` so messages reach **both** WebGL (`StationWebBridge.Publish`) and desktop/Editor WebView2 (`StationGameHost.ReplyPublished`), never calling WebGL-only `StationWebBridge.Publish` directly (`StationSignTransportTests`). Scene displays (`billboard`, `tv`, `linemap`, `clock`, `calligraphy`) and `StationZoneMap` labels instead render 100% natively in C# via `Resources/{Posters,LineMaps,NotoSansSC.ttf}` and off-screen uGUI `Canvas` → `RenderTexture` → `Texture2D.ReadPixels` (`RGBA32`), requiring zero JS round-trips.
- **One pick per pointer event & preview isolation:** `StationLoadCoordinator` runs a final `ApplyVisibility()` after `RegisterWorld` installs `Dense`, `LevelBase`, `StoreyHeight`, and all world targets across initial loads, switches, edits and undo/redo. Canvas pointer handlers (`StationPointerRouter`) build one camera `Ray` per event, route `pointer.*` through `StationSectionDrag` first (`0` scene picks when consumed or on `pointer.up`), and otherwise resolve `StationScenePicker.PickRay` **once** per event against live camera-visible triangles (`StationCellRenderer.TryPickWorld` + `StationScenePicker.Surface` enforcing active `GameObject`, `Renderer.enabled`, camera mask, `ClipInterval`, submesh material culling, negative-scale winding flip, per-triangle `IsPointKept`, and per-tile `StationBatchSpan`s on combined surface meshes, with optional kept-point `WorkPlane` separated from `Cell`), keeping hover/move previews (`StationPlacementPreview`) and exploded tray drags (`StationExplodedView.PickTray`) strictly outside document commits and undo history.
- **No silent fallbacks:** Never substitute a generic cube or hide an unsupported record to make a demo pass. Report unresolved modules via `context.ReportUnresolved(...)` and unported sim features via `Unported` diagnostics.

### 3. Bridge v2, correlated `stationBridge.request`, WebGL & WebView2 transport, artwork & `#game-loading` (`schemaVersion: 2`)

- C# (`StationGameHost` on GameObject `StationGame`) is the sole owner of the committed document revision, camera, simulation clock, statistics history, exploded viewer, active tool and edit session. In-place edits commit via `host.ApplyDocumentEdit` (`StationEditClassifier` classifies changes as `DayOnly`, `Cosmetic`, or `Structural` and stages via `session.StageDocumentEdit` / `CommitDocumentEdit`), preserving the player's `activeLevel`, camera framing, active walkers, clock, `StatisticsRunId`, and 1-minute history across edits and `edit.undo`/`edit.redo`.
- **Player settings, WebGL `1024 / 4096 MiB` heap ceiling & `.jslib` signature rule:** `unity/ProjectSettings/ProjectSettings.asset` sets `runInBackground: 1`, `webGLInitialMemorySize: 1024`, `webGLMaximumMemorySize: 4096`, `webGLMemoryGrowthMode: 2` (geometric growth), `webGLThreadsSupport: 0`, and `webWasm2023: 1` (`2048 MiB` OOMs on Zoo with modules; **do not set `webGLMaximumMemorySize > 4096` in Unity `6000.6.8f1`**, as >4 GiB switches Emscripten to memory64/`BigInt` glue that throws `TypeError: Cannot mix BigInt and other types` during `createUnityInstance` before station code runs).
