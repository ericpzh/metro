# `game/src` module map

A file-by-file ownership map of the game. Keep the dependency rule in mind:
`app/ → render/ → sim/`, and `build/ → sim/` (build imports neither render nor
app). `sim/` imports nothing outside itself and never touches the DOM, three or
React.

## `sim/` — pure simulation

| File | Owns |
|---|---|
| `constants.ts` | Every tuning number, including the time base (`SIM_SECONDS_PER_TICK`, `BASE_TICK_MS`), speeds, LOS bands, gate/escalator/stair/lift/TVM rates, the shared run widths (`ESCALATOR_BAND` / `ESCALATOR_BALUSTRADE`, the two rail-proud clearances, so the model, the envelope and the exit wellways agree), the 屏蔽门 heights (`PSD_FULL_HEIGHT` / `PSD_HALF_HEIGHT`), train stop choreography, agent cap, per-tick re-path budget, and the fixed storey grid `LEVEL_STEPS` + `storeyBand` (the renderer keys every cell to the grid line at or below it). |
| `types.ts` | The data model: `Cell`, `Face`, `Zone`, `GateMode`, `Module` union (`stair.cfg` carries `width`, `style`, `flights` and the `flight` token that makes the lanes of one wide stair a single staircase), `RoomKind` (a walled room's `shop.cfg.kind`), `BillboardVariant`/`BillboardShape`, `BenchVariant`, `StairStyle`, `StairFlight`, `ExitBays`, `LineDef` + `LineDirection` (`up`/`down`, a `travelSign`, per-direction `upTerminus` / `downTerminus`, and a `PsdHeight` 全高/半高), `StationData`, `SaveDoc`, `AgentState`, and `packKey`. The `Module` union includes the 装饰 pieces (`bench` / `shelf` / `desk` / `cubicle` / `sink`, each with `cfg.auto`), the advertising decor (`billboard` with `cfg.variant` + the frozen `cfg.poster`, the ceiling-hung `tv` with `cfg.poster` and `sign`), plus `fence`, the `lift` shaft (`from`/`to` ends) and `vending` (自动贩卖机, a TVM-like stop with its own cabinet). |
| `rng.ts` | The single seeded RNG. All sim randomness goes through it, in fixed order. |
| `stock.ts` | The `STOCK_CLASSES` order (`A/B/C/L`, the single source the worker's pose index and the renderer's decode both read) and the stock table — classifies rolling stock and derives doors, capacity and line throughput. `doorCentres` is the authoritative cadence: one uniform pitch per car, held `DOOR_END_INSET` (2.8 m) off both car ends and rounded symmetrically about the consist centre (a three-door L car therefore spreads its outer doors to the ends, not into the middle); `doorRunOffsets` projects it onto a rail's run, and both the screen doors (`render/models.ts`) and the graph's door servers (`sim/station.ts`) are placed from that one list. |
| `finishes.ts` | The finish table; family decides behaviour, finish decides look. `finishOf`, `floorSpeed`, `DEFAULT_FINISH`, `FINISH_LIST`. |
| `zones.ts` | Fare zones. `ZONE_LIST`, `ZONE_INDEX`, `crossingDir`, labels. A zone boundary is a movement barrier. |
| `gates.ts` | Gate policy predicates: `gateAllows`, `gateLaneAllows`, `nextGateIndex` (the two-way single-lane rule), plus the 闸机 **piece** — `GATE_DOORS` / `gateDoorOf` / `nextGateDoor` (the Tab toggle between a working lane and the fence machine, reading the older `right` / `left` / `none` spellings), `gateHasLane` (a fence machine has none) and `gateMachineSide` / `gateSolidFaces` (the half a fence run may butt into, turned by `rot` — which is why there is no left/right setting). |
| `station.ts` | `buildGraph` and `StationGraph`, servers (`ServerDef`), platforms, `PathFinder` (A* + path cache + per-tick budget), `needsClass`. A `lift` module becomes one `ServerDef` carrying a `LiftCar`: every walkable floor in the column is a stop and every ordered pair is an edge. A `platform-edge` seats **one door server per modelled car door**, on the cell `doorRunOffsets` puts it at (anchored on the edge's own rail, so a screen shorter than its bed still lines up), falling back to spreading its doors over its own run when the edge has lost its rail. |
| `placement.ts` | `ModuleBox`, `moduleEnvelope` (a run reserves exactly the tile it stands in, so a bank of runs touches rather than overlaps; a lift reserves its own 2 × 2 m shaft box; an exit covers its plan), `boxesOverlap`, `placementBlocked` (exits pass stairs/escalators; furniture passes rooms; nothing else shares a box), `moduleAt` (prefers furniture over the room around it; answers a lift from any cell its envelope covers), `placementOnTrack`, `isTrackBed` / `trackBedKeys` / `isTrackCell` (a track bed is either the `floor.track` finish or a `track` module's footprint), `trackAt`, `reservedOpening` (a cell a hand-built block may not cover: a ramp's carved corridor or an exit's floor), `billboardCells` (a banner's run), `benchCells` (a bench's `w`-cell run), and wall/ceiling mounting: `wallSide` (the facing cell a wall-mounted piece bolts to, turned by `rot`), `wallMountStandCell` (the cell a wall-mounted piece stands in — the hovered floor, or the face-adjacent cell when the pointer is on a wall itself, so an ad can bolt to the station wall across the track), `wallMountMissing` (a 广告牌 needs a solid block at the facing neighbour's first course), `ceilingMountMissing` (a 指示牌 / 电视 needs a solid ceiling slab at the next storey grid line). |
| `track.ts` | Track orientation and footprint — the single source the builder, sim and renderer share: `normRot`, `rotateLocal`, `trackFacing`, `trackSide`, `trackDepth`, `trackCells`, `trackCellAt`, `trackCentre`, `trackOriginForCentre`, `edgeCells`. |
| `billboards.ts` | The 装饰 广告牌 formats and the poster catalogue: `BillboardSpec`, `BILLBOARD_SPECS`, `BILLBOARD_VARIANTS`, `billboardSpec` (run length + panel size + silhouette, shared by the builder, the collision helper, the renderer and the palette), and `AdPoster`, `AD_POSTERS`, `adSlugs`, `adPoster`, `postersFor`, `posterFor` — the twelve supplied campaign posters as slugs, each tagged with the silhouettes it is cut for, so the placement roll can offer a landscape panel only landscape artwork. No pixels here: `render/adArt.ts` pairs a slug with its JPEG. |
| `benches.ts` | The 装饰 座椅 variants: `BenchSpec`, `BENCH_SPECS`, `BENCH_VARIANTS`, `benchSpec` — two families (plain stainless with no back, backed seat with arm rests) at 1 m and 2 m, shared by the builder, the collision helper, the renderer and the palette. |
| `fences.ts` | Fence (围栏) joint geometry: `FenceNeighbours`, `FenceArms`, `fenceArms` — turns a cell's fence neighbours (plus rotation for a lone panel) into the arm extents and end caps the renderer draws, so every L / T / + joint is clean without three; a gate counts as one only on its machine side (`gateSolidFaces`). `railLandingAt` lets a fence connect to a stair/escalator landing. |
| `openings.ts` | `carveRampOpenings`, `rampEnvelope`, `rampBlocked`, `rampCorridorHalf`, `rampBodyHalf`, `RAMP_CORE_HALF` (only the cells the run's centreline passes through are the true opening), `rampThinCells` (wall/floor blocks a ramp kept, with the side their half-metre block sits on and its kind), `ESCALATOR_HEADROOM`, `escalatorBasesSolid`, `rampOpeningAt` (the block-brush guard, sharing the carve's ramp list). |
| `stairs.ts` | The four stair shapes, `STAIR_RUN`/`STAIR_RISE`, widths as **lanes** + `nextStairWidth` / `stairLanes` (one, two or three 0.7 m lanes, each fitting one cell), `stairLaneBases` / `planStairLanes` (where a multi-lane flight goes, and how it snaps beside what already stands next to the pointer), `stairLaneMates` (adjacent lanes — their steps always join; `sameFlight`, i.e. a shared `cfg.flight`, means one staircase with no rail along the seam), `stairFlights`, `stairLandings`, level/turn helpers, `stairFacing` / `stairRight` / `stairRotFor` (the run direction, its right, and the placement rotation the exit-bay snap uses). |
| `escalators.ts` | `escalatorModule` (the one fixed one-storey piece), `ESCALATOR_RUN`/`RISE`, `nextEscalatorDir`. |
| `lifts.ts` | Elevator (电梯) shaft geometry: `liftModule` (a 2 × 2 m assembly serving the floor one storey up from its base; its model runs on to that floor's ceiling), `liftExtendedUp`/`liftExtendedDown` (grow a shaft one storey at a time), `liftFootprintCells`, `liftStopZs`, and the door contract `liftDoorDir` / `liftLandingCells` (the world direction the doors face and the two floor tiles in front of them, turned by `rot`) — the one definition of a placed lift, shared by the builder, the graph, the world and the renderer. |
| `exits.ts` | Head-house geometry shared by sim and render: `EXIT_*` constants (the plan, the glass lines, the back wall, the doorway row), `exitSpan` (the plan: the runs' group with one full block of floor at each end), `exitDoorCell`, `exitWallPlanes`, `exitFloorBounds`, `exitCoversCell`, `exitFloorAt` — these take the module list, so a house saved on the old two-metre bays still wraps the runs it really holds — and the six variants: `DEFAULT_EXIT_BAYS`, `exitBays`, `exitBayOffsets` (the side-by-side run columns 0 … bays − 1), `exitCentre`, `exitWidth` (3 / 4 / 5 blocks), `exitSide`, `exitRunHalf` / `exitRunOpenings` (the one-block wellway each run opens, wider only for a run wider than a block), `exitBayCell` (a run column as a world cell, turned by the placement rotation) and `exitRunSnap` (a straight ramp dropped inside snaps into the column under the pointer, clamped to the bay group, one storey down toward the mouth). |
| `agents.ts` | `AgentPool` / `Agent` — the crowd bodies. |
| `sign.ts` | The 指示牌 board as a **document**, pure (no DOM, no canvas, no three): `SignIcon` / `SIGN_ICONS` (the seven pictograms: 列车, 电梯, 无障碍, 卫生间, 扶梯, 楼梯, 出口 — the six bitmaps plus the drawn 出口 plate) and `SIGN_ICON_LABEL`, `SIGN_SIZE` (each kind's printed size in metres) and the panel geometry (`signPanelSize`, `signPlate`, `signContentBox`, `signPieces` — the one layout both the renderer and the editor's hit test read), `signInkSize` / `signPieceSize` (ink + `SIGN_PIECE_PAD`), `settleSignLayout` / `settleSignBins` (pack the row, then measure the board), `packSignRow` / `signLayoutInOrder` (the row is a list read left to right), `stampSignBlock` / `signBlockComponents` / `SIGN_BLOCKS` (the palette's content groups), `defaultSignLayout` (a fresh board: arrow, the station's shield, the 出口 plate, arrow) and `normalizeSignLayout` (repair a save: unique ids, clamped scale, an empty board backfilled). |
| `world.ts` | `World`, `tickOnce`, `Metrics`, trains, collision/separation pass, trip sampling, `trainRenderState`, the elevator car (`stepLift` / `stepLiftRide` / `liftRenderState`); `rebuild()` (an edit: rebuild the graph, keep the crowd), `load()` (a station switch: clear agents, trains, queues, clock and counters) vs `restart()` (empty agents, trains and queues, reseed the RNG, keep the document and the clock). |
| `protocol.ts` | The worker message types (`ToWorker` / `FromWorker`, `GraphInfo`) — `init` / `build` / `control` / `restart`. |
| `worker.ts` | The only sim file that touches `postMessage`; owns the `setInterval` tick loop and the `restart` handler (empty the crowd, keep the station and clock). |

| `rail.ts` | Rail placement and derived screen doors: `RAIL_BED_DEPTH`, `TUNNEL_HEADROOM`, `TUNNEL_SHELL`, `railRect`, `defaultLine`, `setLinePower` (carries a line's 供电 to every track bound to it), `isPlatformCell`, `trackPieceForLine`, `makeTrack`, `derivePlatformEdges`, `dropDerivedEdges`, `regenerateRailEdges`, `trackInterferenceBlocked` / `trackClearanceBlocked` / `trackFloorMissing` / `trackBlockReason` (eligibility: nothing may share the run's space; a platform needs solid floor and open headroom), `commitTrack`, `placeTrack` (a fixed piece), `placeRail` (the legacy axis-aligned rect), `resizeTrack`, `freeTunnelEnd` / `makeTunnel` / `placeTunnel` (auto-extend a rail off the free end nearest the hovered cell; bores the wall through and raises a shell, no platform doors), `stripTunnelShell`, `railModuleAt`, `railSummary`. Pure document edits. |

## `render/` — three.js

| File | Owns |
|---|---|
| `chunkMesher.ts` | `meshChunk`, `CHUNK`/`CORNER_R`/`BEVEL`, rounded-corner voxel geometry grouped into one part per finish. |
| `materials.ts` | The procedural material kit (`createMaterials`, `MaterialSet`, `contactShadowTexture`). |
| `models.ts` | Procedural module geometry: `buildModule`, `setGateWing`, `rollEscalator`, `buildTrain`, `buildCab`, `setDoors` / `setDoorsSides`, `createModelMaterials`, `TrainPose`. Draws 售票机 and its 自动贩卖机 sibling, the 装饰 pieces (the 座椅 variants — a backless stainless bench and a backed, chained seat — the 货架 supermarket gondola with its perforated back panel, five shelves, price rails and instanced colourful goods, desk / cubicle / sink / wall-mounted ad lightbox, and the ceiling-hung 指示牌 and 电视, each with its lit double-sided face), the fence panel from `fenceArms`, the 供电 models (guarded 第三轨 conductor rail, overhead 接触网 wire), the covered exit as a red portal frame under a blue waved roof (or a glass railing when uncovered; the name board hangs off the canopy at the doorway when covered, and lies over the mouth railing's glass facing back up the runs when not), and the 电梯 shaft with its moving cabin (`buildLift`, cabin in `userData.liftCabin`, a sill + call panel at each real landing). A train wears the same cab at **both** ends (`buildCab`), differing only in its lamps (white leading, red trailing), and its two door banks are tagged by side so only the bank with screen doors to meet opens. The 广州地铁 mark is one drawing (`drawMetroMark`), worn by the cab's nose and the exit banner alike. Platform screen headers print the bound line's per-direction terminus, at full or half height; the screen is cut open at `doorRunOffsets`, re-anchored on the edge's rail so the openings stand on the car doors. The only pixels in the kit are the 广告牌 / 电视 posters, which arrive as `ctx.ads.adFace` quads (`render/adArt.ts`), and the 指示牌 pictograms (`render/pictograms.ts`); everything else is procedural, with no other image or GLB asset. |
| `adArt.ts` | The poster artwork: `createAdArt` → `AdArt` (`load`, `adFace`, `dispose`), `AdFace`. Pairs each `sim/billboards.ts` slug with the JPEG beside it in `src/assets/posters/` (not `ads/` — EasyList blocks `/assets/ads/*`, which in dev would reject this module's whole graph), decodes every one up front (a material minted around an image-less texture uploads empty and stays blank, and the crop needs the image's real size when the quad is cut), then hands out a lit `MeshBasicMaterial` plus a `PlaneGeometry` whose UVs show the centred window that fits the poster to the panel. Placeholder face for a slug this build cannot print; `dispose` takes back every texture, material and geometry it made. |
| `pictograms.ts` | The 指示牌 pictogram artwork, browser-only: `loadPictograms()` decodes the PNGs in `src/assets/pictograms/` (one per `sim/sign.ts` `SIGN_ICONS` entry but 出口, which is drawn as the green 出/EXIT plate) once per page from base64 data URLs, and hands them to `render/signFace.ts`'s registry (`setPictograms`). Every caller awaits it before drawing a board, because a plate is a texture minted once and a mark that arrives late never reaches it — `scene.ts` rebuilds its modules, `app/moduleThumbnails.ts` waits, `app/SignEditor.tsx` redraws its tiles. Pure states and mounts live in `signFace.ts` so the drawing still runs in Node. |
| `panelUv.ts` | The crop arithmetic, pure enough to run in Node: `UvWindow`, `panelUvWindow` (the centred window that fits one aspect to another), `croppedPlane` (a `PlaneGeometry` whose UV corners walk that window in three's own order). Checked by `test/billboard.test.mjs`. |
| `moduleGhostKey.ts` | The identity of a module **as a hover ghost**: `moduleGhostKey`. `SceneRenderer.setModulePreview` skips a rebuild whose key matches the one already drawn, so everything that changes what a ghost looks like has to be named here — the piece, its cell and `rot`, a stair's shape, an escalator's direction, a track's line/power, a bench's or 广告牌's variant, and the 闸机 door side (Tab). Pure, so the contract is testable in Node (`test/gate-door.test.mjs`); the matching store-side subscription is `placementPreviewKey` in `app/store.ts`. |
| `signFace.ts` | The 指示牌's pixels — the *only* code that draws a board, pure enough to run in Node: `drawSignPanel(g, layout, ctx, face)` paints one face of the plate (ground, frame, then each measured piece), and `ctx` carries the station's lines, the panel's own size in metres and an optional pixels-per-metre. Owns the ink/ground/frame colours, `drawArrow`, `drawLineBadge` (the line's name exactly as 线路 spells it, in its own colour), `drawText` (a label's rows), the drawn 出/EXIT plate, and the pictogram **registry** (`pictograms` / `setPictograms` / `SignIconArt`) that `render/pictograms.ts` fills — a mark is `drawImage`d from its bitmap, so a drawing happens only when the art is in the registry. Checked by `test/sign-render.test.mjs`, which decodes the real assets and reads back what a board printed. |
| `levelSlicing.ts` | The whole of the level slice, pure: `LevelSide` (`active` / `below` / `above`), `levelSide` (which side of the edited storey a piece sits on — a lift from -12 to -4 is *active* at -8, because its span covers that storey), `levelVisible` (显示其他层 off draws the edited storey alone at every angle; on ghosts the neighbours, and a storey above keeps only the `unsupported` plates so a room never wears its own ceiling), `unsupportedAbove` (a fixture's version of the chunk mesher's `float`: its column's lowest storey is above the active one), `trainVisible` (the slice *and* the sim's own `parked` flag) and `crowdVisible`. Checked by `test/level-slicing.test.mjs`. |
| `stationDisplay.ts` | The 电视 station board's derivation and pixels, testable without a canvas: `stationDisplayLayout` (the whole-screen plate geometry — header, 本趟/下趟/第三趟 cards, service strip, clock and the content window, in that order down the information column, the window never leaving the plate) and `tvLineStatus` (the next train off the live poses: approaching reads as the countdown, level with the berth as 列车进站, past / opposite-track / other-line ignored, no terminus falls back to the direction word). Checked by `test/station-display.test.mjs`. |
| `scene.ts` | `SceneRenderer`, `SceneStats`, `PickResult` — the plain three.js scene driven by the Viewport. Meshes cells by `storeyBand` (hiding the slab at each lift stop above its base so the shaft is a real opening), applies the level slice through `render/levelSlicing.ts` (`setLevel`, `setAutoCeiling`), owns the live fence-drag preview (`setFencePreview`), glides elevator cabins from the worker's poses (`setLifts`), picks a placed module from its drawn meshes (`pickModule`), boxes the selected module (`setSelection`), fades walls/screens (`setHideWalls`), hides every ramp-kept block and draws its half-metre panel (`buildRampThins`), clips the crowd with the cutaway, and owns the ad artwork — one `AdArt` per scene, redrawing the modules once the posters decode so a screen never keeps its placeholder. |

## `app/` — React shell (panels only, no sim logic)

| File | Owns |
|---|---|
| `store.ts` | zustand app state: the station document, active tool/brush/rotation/width/direction, the 闸机 `gateDoor` toggle (lane or fence), view flags (`ghostOtherLevels`, `autoCeiling`, `cutaway`, `hideWalls`, `ortho`), the 地基 `autoWalls` toggle, metrics, selection, and the worker plumbing (`initSim`, `rebuildSim`, `restartSim`, `setFrameHandler`, whose state frame now carries the lift poses). `placementPreviewKey` is the one string the viewport subscribes to for the equipment hover ghost (piece, rotation, and every Tab cycle), so R and Tab redraw a ghost already under the pointer. Rail and line actions (`layTrack`, `layTunnel`, `rotateRail`, `cycleRailDir`, `setTunnelLength`, `regenRail`, `refreshRailDoors`, `removeRail`, `updateRail`, `updateLine` — a 供电 or 屏蔽门 change carries to every bound track / edge — `addLine`), `MODULE_OPTIONS` (including 电梯, 自动贩卖机, the four 座椅 variants and the six 出入口 variants), `FACILITY_OPTIONS`, tool predicates (`isStairType`, `isBillboardType`, `isBenchType`, `isExitType`, `isDecorType`, `isWallMountedType`, `isFenceType`, `isGateType`, `isFacilityBrush`, `isRotatableType`). |
| `App.tsx` | Top bar (播放 / 暂停, 重启, and multiplier-only speed chips), the folding inspector (`Folder` / `Disclosure`: 信息, one selectable `ExitCard` per exit, and the 线路 cards whose `LineFields` include the 上行终点 / 下行终点 termini and the 屏蔽门 全高 / 半高 choice), bottom metric bar (FPS + 方块数), global keyboard shortcuts (**Z** 选择, **B** 删除, **F** 地基, **G** 墙, **P** 分区, **L** 轨道, **J** 设备, **Tab** flips 自动生成墙壁 in the 地基 tool and cycles width/direction elsewhere, **Space** play/pause, **Home** frames the view), and the per-tool stage hint (地基 / 装饰 / 围栏 / 电梯 / 出入口 / 指示牌 wording). |
| `LeftRail.tsx` | The blueprint build rail: folders for 工具 (选择 / 地基 + its 自动生成墙壁 toggle / 墙 / 删除), 设备, 轨道 (站台 **L**, 旋转 **R**), 房间, 装饰, 材质 (单块 **N** / 整面 **M** / 取色 **I**), 分区, 视图 (显示其他层 **X** / 隐藏天花板 **H** / 剖切 **C** / 隐藏墙壁 / 热力图 / 分区图). Every tile with a keyboard shortcut shows it as a badge on hover/focus (undo/redo carry Ctrl+Z / Ctrl+Y; Tab marks the contextual width / direction / auto-wall toggles); 装饰 (货架 / 办公桌 / 厕所隔间 / 洗手池, the 座椅 nested sub-menu of two families × two widths, the 广告牌 nested sub-menu of six formats, 电视, 指示牌), surfaces, zones, view. |
| `Viewport.tsx` | Owns the `SceneRenderer` lifecycle and turns pointer input into build commands (the 地基 (auto walls toggleable) / 墙 / 删除 / equipment / 装饰 / 围栏 drag / paint / zone / 站台 / 隧道 tools, the 电梯 place-or-extend hover, and a straight ramp snapping into an exit bay via `exitRunSnap`). Select and 删除 test the drawn mesh first (`SceneRenderer.pickModule`), so a whole module is selected/deleted rather than the block beneath it, and `removePlacedModule` routes rails and rooms through their own teardown; a 围栏 panel is dragged into a straight line the release lifts whole, while a 设备 / 装饰 drag sweeps up same-type pieces through `sweep.ts` and bulldozes the run in one commit. Cancels a previewing area drag on ESC, a second press, or the other button's release; keeps the 3D selection box in step with `selected`. A wall-mounted 广告牌 resolves its stand cell through `wallMountStandCell` (the hovered floor, or the face-adjacent cell when the pointer is on a wall), so it can mount over a track, and the first station build frames the home iso view (`framedRef`) while later edits leave the camera alone. The only app file that touches three directly. |
| `sweep.ts` | The 删除 tool's same-type drag sweep: `sweepFamily` (which palette piece a module is, so a 2 m 座椅 never takes the 1 m ones; null for rooms, rails, 出入口, 楼梯 / 扶梯 / 电梯, 站台门 and 围栏, which have their own teardown), `sweepThrough` (grows the pending list with the matching pieces the pointer *crossed*, sampling the path between two move events so a fast flick skips none), and `removeSweptModules` (folds the whole run into one state, so one `Ctrl+Z` puts it back). Pure — the picking itself stays in the Viewport. |
| `SignEditor.tsx` | The 指示牌 board editor: the drag surface over the `sim/sign.ts` document (the pair of boards, preview-never-commits, confirming makes the pair current and the next hung sign a copy). Redraws its tiles once `render/pictograms.ts` has loaded the mark art. Checked by `test/sign-editor.test.mjs`. |
| `ViewCube.tsx` | The orientation cube and its depth rail. Only ever moves the camera: a face / edge / corner click (or Home) must not touch the level slice, or the 显示其他层 tile reads as broken. |
| `Lab.tsx` | The `/lab` material/renderer lab. |
